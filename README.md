# India's Space Software Ecosystem

A beginner-first guide to India's space-data platforms (MOSDAC, NASA Earthdata, Copernicus), built during the Agnirva Software Internship Program (Onboarded by AICTE under NEAT 5.0).

## The Problem
First-time engineering students know satellite data exists, but cannot tell a data portal, an API, and a processing tool apart, cannot choose between platforms, and often give up when documentation is unclear.

## What's Included
- **Data Portal Map**: classifies each platform into portal / API / tool
- **Task-Based Pathways**: step-by-step routes from a goal (e.g. "find rainfall data") to a first action
- **Glossary**: plain-language definitions of key terms
- **Source citations**: every claim traces to the platform's own public documentation
- **Project report** in `/docs`
