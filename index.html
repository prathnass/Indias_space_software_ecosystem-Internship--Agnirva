A beginner's starting map for Indian space-data platforms

Stuck trying to find satellite data? Start here.

Most students hit the same wall with MOSDAC, NASA Earthdata, or Copernicus — not because they don't understand space, but because no one explains the difference between a portal, an API, and a tool. This page does.

Built directly from the public documentation of MOSDAC (ISRO), NASA Earthdata, and the Copernicus Data Space Ecosystem — every claim on this page is traceable to a named source.

02

Task-Based Pathways

Pick the goal closest to yours. Each pathway gives you one concrete next step — not a list of every option.

Goal: Find satellite rainfall data for your region
  1. Go to the MOSDAC portal at mosdac.gov.inThis is the Portal layer — you're browsing, not calling an API yet.
  2. Navigate to "Atmospheric Products"This is where rainfall and precipitation datasets are grouped.
  3. Select a rainfall/precipitation dataset and your date rangeCheck the Glossary below for what "date range" options actually mean here.
  4. Download in GeoTIFF or NetCDF formatBoth are file formats for geographic data — see Glossary for which one fits your analysis tool.
Goal: Find land-use or land-cover data
  1. Go to the Copernicus Data Space browser at dataspace.copernicus.euThis is the Portal layer of Copernicus — visual browsing, no API call needed yet.
  2. Search by area of interestDraw or type your region of India directly on the map view.
  3. Filter by Sentinel-2 Level-2A productThis product type is already corrected for atmospheric effects — easiest for beginners.
  4. Download the scene directly from the browserNo authentication token needed for this step — that's only required if you move to the API later.
03

Glossary

The same term means the same thing everywhere on this page. Search or scan below.

Portal
A website where you browse and download data by clicking through menus — no coding needed.
API
Application Programming Interface. A way for a program (not a human clicking buttons) to request data directly from a platform.
Tool
Software used after downloading data, to open, view, or process it — separate from the portal or API you got it from.
Endpoint
A specific web address an API responds to — think of it as one "counter" at a service desk that handles one type of request.
Authentication
Proving who you are to an API, usually with a token, before it will respond to your request.
Token
A piece of text that acts like a temporary password, proving to an API that you're allowed to access it.
GeoTIFF
An image file format that also stores exact geographic location — common for satellite imagery.
NetCDF
A file format built for large, multi-dimensional scientific data, such as data that varies by time and location together.
Level-2A product
Satellite data that has already been corrected for atmospheric interference — more ready-to-use than raw (Level-1) data.
